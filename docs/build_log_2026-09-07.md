## Scientific findings

The live catalog contains 47,731 mapped rows, including 72 preferred eligible
JunoCam observations. The earlier mapped sample had 93 observation stems;
21 additional methane observations are withheld by existing bloom flags.
No RGB observation was removed by that additional test. Ten observations
with failed geometry were already absent. The old six-version polar file
is preserved and now exposes three independent observations; irregular
approximately 577/243-second gaps prevent a constant-cadence triple.

The calibrated collection contains 37,386 tiles from PJ13–36. Three sampled
GeoTIFFs have 62.5 km pixels, five generated channels and nil/inapplicable
acquisition times. Actual FITS headers/rows expose scaling and mask
ambiguities in the guide/labels. It is a supplemental derived reference,
not a replacement for native observations for motion or radiance spectra.
See the [full audit](reports/junocam_calibrated_assessment_2026-09-07.md).

## Scope and judgment calls

Implemented the accepted review rather than reopening its design decisions.
Chose documented image/interval exclusions plus withholding unassessed states;
a bloom flag is a conservative measured exclusion, not proof of a documented
hardware incident. Retained verified-clean legacy PJ4 viewing without
claiming absolute radiometric or wind validation. Chose explicit incompatible
states when grids or vector associations cannot be established. Population
uncertainty uses independent passes rather than overlapping strips. Kept the
calibrated bundle as a reference and preserved native/published data.

No bulk image mirroring, new wind interpretation, physical-model changes
or ground-truth modification occurred. The authorized GitHub delivery
contains code and documentation. This mirror
still lacks a generally associated vector product and a suitable JunoCam
regular-cadence sample; the interface reports those data limits honestly.

For the teaching refresh, included the companion deck and retained historical
JIRAM evidence with explicit instrument/revision scope. Corrected the recipe's
cutoff description rather than changing the already consistent numerical
mask. Kept source filenames as citations while removing executor model names
from teaching prose. The owner explicitly authorized GitHub delivery of both
the implementation and this documentation follow-up.

For the illustrated-guide refresh, used normal desktop captures and preserved
scientific colours instead of the original forced image-size/palette limit.
Kept older numbered captures as unreferenced historical records, reused the
existing current statistics/readiness images, and described actual orbit
browsing instead of implying exact source membership. No new scientific
interpretation or application behavior was introduced.
