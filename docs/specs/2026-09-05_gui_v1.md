## Data facts
- `frames_with_geo(mirror)` returns ~113,000 rows (one per frame and
  band half); rows that see the planet have `on_planet_frac > 0`
  (~47,600). Columns used: `product_id`, `orbit_dir`, `half`, `band`,
  `seq_id`, `start_time`, `bore_lat`, `bore_lon_east`, `bore_emission`,
  `on_planet_frac`, `median_pixel_km`, `dayside_frac`, `pole_inside`,
  `min_lat`, `max_lat`, `geo_ok`. Load once per process into a
  module-level cache (`data.py`), reduced to these columns and to rows
  with `geo_ok & on_planet_frac > 0`.
- Strips index (`load_index`): columns `strip_id`, `orbit`, `band`,
  `n_frames`, `time_start`, `time_end`, `time_mid`, `center_lat`,
  `center_lon_east`, `km_per_px`, `resolution_class`, `valid_frac`,
  `dayside_frac`, `median_emission`, `lat_min`, `lat_max`,
  `lon_min_east`, `lon_max_east`, `lon_span_deg`, `pole_inside`,
  `path`, `rows`, `cols`. `read_strip(mirror, strip_id)` -> Dataset
  dims `(y, x)` with `image`, `valid`, `emission`, `incidence`,
  `local_time_h`, coords `x_km`, `y_km`, `lat`, `lon_east`.
- Stacks: `<mirror>/regions/<region>/*.nc`, dims `(time, y, x)`, vars
  `image`, `valid`, `emission`, coords `lat`, `lon_east`, `x_km`,
  `y_km`, per-time coords `product_id`, `seq_id`, `orbit`; attrs
  `level`, `band`, `region`, `km_per_px`. Frame stacks can be 2 GB:
  open lazily (`xr.open_dataset`, no `.load()`), read one time index at
  a time. Row index increases with +y: display with `origin="lower"`
  semantics (in HoloViews, pass explicit `bounds` from `x_km`/`y_km`
  and do not flip arrays).
- Trackability (optional): `index/trackability_frames.parquet` with
  `product_id`, `has_partner`, `best_dt_s`, `trackable_30`.

## Architecture (normative)
- `state.py`: `class CatalogState(param.Parameterized)` with filter
  parameters (orbit range, date range, band, resolution max km,
  emission max, on-planet min, dayside only, latitude band, revisit
  only), `selection` (list of product ids), `current_stack` (path),
  `current_strip` (strip id), and `to_json()`/`from_json()` for
  saving a session.
- `data.py`: cached loaders (`catalog_table(mirror)`, `strips_table(mirror)`,
  `trackability_table(mirror)`, `open_stack(path)`, `open_strip(mirror, id)`,
  `strip_stats(mirror, id)` computing `strip_statistics` once and caching
  to `<mirror>/gui_cache/stats_<strip_id>.nc`), plus `apply_filters(table, state)`.
- `views_catalog.py`: `build(state, mirror) -> pn.Column`. Map: hvplot
  points of (`bore_lon_east`, `bore_lat`) with `rasterize=True`
  (datashader) for the full filtered set; when the filtered set has
  fewer than 5,000 rows, overlay interactive points with hover
  (product id, time, pixel km, emission) and a `BoundsXY` box-select
  stream that sets `state.selection`. Polar-view toggle (`N`, `S`,
  `cyl`): polar view plots `x = rho*cos(lon)`, `y = rho*sin(lon)` with
  `rho = 90 - |lat|`. Coverage panel: bar charts of filtered counts by
  latitude band (7 bands as in `trackability`) and by orbit, and a
  time line (counts per month). Selection table (`pn.widgets.Tabulator`,
  paginated) with a CSV download and "send to Poles"/"send to Strips"
  buttons that set the other tabs' inputs (orbit list; latitude band).
- `views_poles.py`: stack chooser (`pn.widgets.Select` over files found
  under `<mirror>/regions/`, plus a text input for any path); viewer:
  `hv.Image` of the current time index with explicit km bounds, a
  `pn.widgets.Player` over time, percentile stretch (computed once on a
  subsample of the stack; sliders for the percentiles), colour map
  select, graticule overlay (contours of `lat` every 2 deg and of
  unwrapped `lon_east` every 30 deg, drawn from the stack's coordinate
  arrays; handle the 0/360 wrap by contouring `sin` and `cos` or by
  masking the seam), emission overlay toggle (alpha 0.4), metadata pane
  (product id, seq id, orbit, time, level). Actions: "Render movie"
  (calls `movie.write_movie` in a thread, progress indicator, output
  path shown) and "Export goflow triples" (`export_goflow.export_stack`
  to a chosen directory), "Save PNG" of the current view.
- `views_strips.py`: filters bound to state (latitude band, epoch
  range, resolution max, valid fraction min, dayside min, band); table
  of matching strips (Tabulator, row click sets `state.current_strip`);
  map of strip centres coloured by year with hover (id, extents, km/px);
  viewer for the current strip (image with km bounds, graticule as
  above, local-time contours every 2 h, mask as transparency, cursor
  readout via hover of lat, lon, local time, emission); statistics
  panel with three hvplot curves from `strip_stats`: isotropic spectrum
  (log-log, k in rad/m and a secondary axis label in km wavelength),
  1-D spectra along x and y, structure functions orders 2 and 3 vs r in
  km; "Export filtered list (CSV)".
- `app.py`: `build(mirror) -> pn.Tabs` with the three tabs and a
  header showing the mirror path and row counts; `serve(mirror, port,
  address, show)` calling `pn.serve`. Template: `pn.template.FastListTemplate`
  with the filters in the sidebar for the active tab.
- `gui_cmd.py`: `jiram-catalog gui [--mirror] [--port 5006] [--address 127.0.0.1] [--no-browser]`.
- Performance: the catalog table must render the first map within 5 s
  after the data is loaded; loading the table itself may take longer
  (show a loading indicator). Never load a full frame stack into
  memory.
- No network calls; no JavaScript written by hand; no custom CSS beyond
  what the template provides.

## Offline tests (`tests/test_gui_offline.py`; synthetic tables, no mirror, no server)
`apply_filters` on a synthetic catalog table for each filter; polar
view coordinate transform; `CatalogState.to_json/from_json` round trip;
`views_catalog.build`, `views_poles.build`, `views_strips.build` and
`app.build` instantiate with monkeypatched loaders returning synthetic
data (a 2-time-step 32x32 synthetic stack Dataset, a 2-row strips index
with two 32x32 synthetic strip Datasets) and `pn.panel(obj).save(tmp)`
writes a non-empty HTML file for each tab; the graticule helper returns
contour paths for a synthetic lat/lon grid including a seam crossing.

succeeds; the catalog table has >= 40,000 rows; the strips table >= 200
rows; opening `regions/north_pole_paper/M_orbits4_sequence.nc` in the

answers `GET /` with HTTP 200 within 90 s and is then terminated.
