## API (exact names)
```python
def power_spectrum_2d(field, valid=None, *, dx_m, window="tukey", alpha=0.25, detrend="mean", fill=0.0, correction="valid_frac") -> dict
    # keys: "power" (ny, nx) float64 = |f_hat|^2 with the conventions-doc forward FFT (fftshifted),
    #       "kx", "ky" (1-D, rad/m, fftshifted), "variance" (of the windowed, filled field),
    #       "valid_frac", "window_power" (mean of window^2 over the grid), "meta" (dict of options)
def isotropic_spectrum(spec, *, nbins=None) -> dict   # "k" (bin centres, rad/m), "E" (shell-integrated energy density per unit k, so that sum(E*dk) == variance up to the population counting), "count" (lattice points per shell), "dk"
def spectrum_1d(field, valid=None, *, dx_m, axis, window="tukey", alpha=0.25, min_valid_frac=0.9) -> dict  # "k", "P" averaged over all lines along `axis` (rows for axis=1, columns for axis=0) that are at least min_valid_frac valid; "n_lines"
def structure_function(field, valid=None, *, dx_m, orders=(2, 3), max_lag_px=64, direction="isotropic") -> dict  # "r_m", "S" {order: array}, "count"; only pairs with both points valid; direction "x", "y", or "isotropic" (average of x and y at equal lag)
class BicoherenceAccumulator:
    def __init__(self, n_fft: int, dx_m: float, *, window="hann"): ...
    def add_lines(self, lines: np.ndarray, valid: np.ndarray | None = None, *, min_valid_frac=0.95) -> int   # lines (n, n_fft) segments; returns number accepted
    def add_field(self, field, valid=None, *, axis=1, step=None) -> int   # cuts every line along axis into non-overlapping n_fft segments
    def result(self) -> dict   # "k1", "k2" (rad/m), "b2" (bicoherence squared, normalised so it lies in [0,1]), "n_segments", "bispectrum" (complex)
def strip_statistics(ds: xr.Dataset, *, max_lag_px=64) -> xr.Dataset   # the standard set for one strip: isotropic spectrum, 1-D spectra along x and y, structure functions orders 2,3; coords k, r; attrs copied from the strip (strip_id, km_per_px, band, orbit, time_mid, valid_frac)
def population_statistics(paths: Sequence[str | Path], *, n_fft=256) -> xr.Dataset   # for strips of ONE resolution class: mean and standard error of the isotropic spectrum and 1-D spectra across strips (interpolated onto the common k grid of the first strip), plus a bicoherence accumulated over all strips' rows along x; attrs: n_strips, km_per_px
```
Decisions: fields are float64 inside; NaN and `~valid` pixels are set
to `fill` after detrending (the mean is computed over valid pixels
only); the window is separable Tukey (or Hann) applied to the full
canvas; `correction="valid_frac"` divides `power` by
`valid_frac * window_power` so that a fully valid, unwindowed field has
Parseval exactly and a masked field is unbiased in total variance to
first order (document the residual bias in the docstring; offer
`correction="none"`). Wavenumbers are angular (`2*pi*np.fft.fftfreq(n,
d=dx)`), shell bins have width `dk = 2*pi/(max(nx,ny)*dx)` by default,
and `E(k)` is the sum of `power` over lattice points in the shell
divided by `dk`, exactly as the conventions document defines shell
spectra (use its population counting). Structure functions use
vectorised shifted-array differences with the joint validity mask (no
Python loops over pixels; a loop over lags is fine). The bicoherence
estimator is the standard normalised one,
`b2 = |sum X(k1) X(k2) X*(k1+k2)|^2 / (sum |X(k1) X(k2)|^2 * sum |X(k1+k2)|^2)`,
accumulated over segments, for `k1, k2 >= 0` and `k1 + k2 < Nyquist`.

## Offline tests (`tests/test_stats2d_offline.py`) — these are also the gate, so they must be exactly these checks
1. Parseval: a 256x256 white-noise field, `valid=None`, `window=None`,
   `correction="none"`: `sum(power) == variance` within 1e-9 relative;
   and `sum(E*dk)` over the isotropic spectrum equals `sum(power)`
   within 1e-9 (population counting covers every lattice point).
2. Wavenumber axis: a pure sinusoid of wavelength 10 px along x has its
   power peak at `|kx| == 2*pi/(10*dx)` within half a bin, and zero
   power along ky except the DC line.
3. Power-law recovery: a 512x512 Gaussian random field generated in
   Fourier space with `E(k) ∝ k^-3` (isotropic, random phases): the
   least-squares slope of `log E` vs `log k` between wavelengths 64 px
   and 8 px is within 0.1 of -3 for the full field, and within 0.2 with
   a mask that removes 15% of pixels as a few smooth blobs (build the
   blobs by thresholding a low-pass filtered noise field), using the
   default window and correction.
4. Structure function: on a 64x64 random field with a random 20% mask,
   `structure_function(..., orders=(2,), max_lag_px=5, direction="x")`
   equals a brute-force double loop over valid pairs within 1e-12.
5. Bicoherence: 400 segments of length 256 of
   `cos(k1 x + φ1) + cos(k2 x + φ2) + 0.5 cos((k1+k2) x + φ1 + φ2) + 0.3 noise`
   with `φ1, φ2` random per segment give `b2(k1, k2) > 0.5` at the
   coupled bin and `b2 < 0.1` for the same three cosines with an
   independent random phase on the third term.
6. `spectrum_1d` on the sinusoid field (axis=1) peaks at the same
   wavenumber; lines with too many invalid pixels are excluded
   (`n_lines` reflects it).
7. `strip_statistics` and `population_statistics` on three synthetic
   strip-like Datasets (same shape and `km_per_px`) return the expected
   variables, coords, and `n_strips == 3`.
