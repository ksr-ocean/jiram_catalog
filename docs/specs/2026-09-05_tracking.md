## `tracking.py`
- `track_pair(img0, img1, *, template=15, search=35, step=1, positions=None, min_valid_frac=0.9, min_ncc=0.5) -> np.ndarray`:
  for each template centre (either the given integer `positions`
  array of shape (N, 2) as (row, col), or a regular grid with `step`
  over the region where a full template and search window fit), take
  the `template x template` patch of `img0` centred there, and compute
  the normalised cross-correlation with every `template x template`
  window of `img1` whose centre lies within the `search x search`
  neighbourhood; pixels that are 0 or NaN are invalid: skip templates
  with fewer than `min_valid_frac` valid pixels, and evaluate NCC only
  over pixels valid in both patches (requiring the same fraction).
  Take the peak, refine it to sub-pixel with a 2-D parabolic fit on
  the 3x3 neighbourhood of the peak (skip refinement at the search
  border), and reject peaks with NCC < `min_ncc`. Return an array (M,
  6): row0, col0, drow, dcol, ncc, n_valid. Vectorise over templates
  in batches (e.g. `numpy.lib.stride_tricks.sliding_window_view` on
  `img1` for one template at a time is acceptable if the total for
  ~20,000 templates runs in under 5 minutes; report the throughput).
- `read_tp4(path) -> tuple[np.ndarray, dict]`: the (N, 8) table and
  its label (via `vicar.read_vicar`).
- `match_vectors(ours, theirs, index_base) -> pd.DataFrame`: join on
  the integer template position (accounting for `index_base` and the
  (sample, line) vs (row, col) order), returning per-vector
  differences in displacement (px) and speed (m/s).

## `scripts/classical_tracking_pj4.py`
1. Determine `index_base` empirically: for `n0103aa.tp4`, compare the
   set of template positions with the nonzero footprint of `n01a.map`
   (positions must lie inside the footprint with a margin >= 7 px under
   exactly one of the two conventions). Report it.
2. Tracker validation (A): for the pairs `aa, bb, cc, dd, ee, ff, gg,
   hh, ii, jj, kk, ll` of `n0103` and of `n0204` (24 files), run
   `track_pair` on the paper maps at the TRACKER4 template positions
   subsampled every 4th vector (so ~3,000 per file), with template 15,
   search 35, `min_ncc` 0.5. Match to the TRACKER4 vectors and report,
   per file and pooled: N matched, median and 90th percentile of
   `|d(drow, dcol)|` (px, Euclidean), fraction within 0.5, 1, 2 px, and
   the median of the paper's NCC-equivalent if available (it is not
   stored; skip). Also the pooled median absolute speed difference in
   m/s using `MPS*1000/DT` from the `.tp4` label.
3. Pipeline validation (B): repeat (A) for the same 24 pairs but with
   OUR reprojected frames from the raw archive (both frames of the pair
   reprojected with `PAPER_GRID`) in place of the paper maps, at the
   same template positions; report the same statistics against the
   TRACKER4 vectors.
4. Write `docs/reports/tracking_pj4.json` with keys `index_base`,
   `params`, `A` and `B` each holding `pooled` (`n`, `median_px`,
   `p90_px`, `frac_05`, `frac_1`, `frac_2`, `median_speed_diff_ms`) and
   `per_file` lists; and `docs/reports/tracking_pj4.md` with the same
   in tables plus a short method description and the throughput.

## Offline tests (`tests/test_tracking_offline.py`)
- Synthetic pair: a random smooth field shifted by a known sub-pixel
  vector (e.g. (2.3, -1.7) px via Fourier shift); `track_pair` recovers
  it within 0.1 px at >= 95% of templates; invalid (zero) regions are
  skipped; NCC threshold rejects a pure-noise second image.
- Parabolic refinement on a synthetic peak.
- `read_tp4` on `n0103aa.tp4` (shape (N, 8); col4 == col2 - col0 within
  1e-4; col6 == col4*MPS*1000/DT within 0.5 m/s).
- `match_vectors` on synthetic tables under both index bases.
